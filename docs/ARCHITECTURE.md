# BISHENG 系统架构设计文档

## 4+1 视图模型

本文档采用4+1视图模型描述BISHENG（毕昇）LLM应用开发平台的系统架构。

---

## 1. 场景视图（Scenario View）

### 1.1 系统概述

BISHENG是一款开源的LLM（大语言模型）应用开发平台，主攻企业场景，已有大量行业头部组织及世界500强企业在使用。平台提供工作流编排、知识库管理、Agent开发、文档审核、报告生成等核心能力。

## 6. 系统特性

### 6.1 企业级特性

| 特性 | 描述 |
|------|------|
| 权限管理 | 基于角色的细颗粒度权限管理(RBAC)，支持用户组管理 |
| SSO/LDAP | 支持企业单点登录和LDAP集成 |
| 安全审计 | 完整的操作日志记录和审计功能 |
| 分组流量控制 | 支持按分组进行API流量控制 |
| 监控统计 | 系统运行监控和业务统计分析 |

### 6.2 技术特性

| 特性 | 描述 |
|------|------|
| Human in the Loop | 支持用户在Workflow执行中间过程进行干预和反馈 |
| 工作流编排 | 支持成环、并行、跑批、判断逻辑等复杂编排 |
| 多模型支持 | 支持OpenAI、智谱、文心、通义等主流大模型 |
| 高精度文档解析 | 支持PDF、Word、Excel等多种文档的高精度解析 |
| Agent能力 | 支持多智能体协作，具备专家级品味的灵思Agent |
